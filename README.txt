THE LAST FOOTPRINT — WEBSITE FILES

HOW TO RUN
1. Download and extract last_footprint_website.zip.
2. Keep index.html, explore.html, story.html, about.html, contact.html, style.css and script.js in the same folder.
3. Open index.html in a browser.
4. For the best development experience, open the folder in VS Code and use the Live Server extension.

PAGES
- index.html: animated-feel landing page and introduction
- explore.html: six destination cards
- story.html: one reusable story page; JavaScript loads the correct story using ?place=mars, ?place=moon, etc.
- about.html: project purpose
- contact.html: contact form interface
- style.css: layout, colors, responsive design and retro space styling
- script.js: mobile navigation, story content and contact-form demo behavior

IMPORTANT NOTES
- The contact form currently validates input and displays a demo confirmation. It does NOT send or store messages. Connect Formspree, EmailJS, or your own backend to receive real submissions.
- Google Fonts are loaded online. If offline, the site uses fallback fonts.
- Mission facts and status can change. Verify details with official mission sources before presenting this as a factual reference.
- “Left behind” is used broadly in the storytelling. Some spacecraft are still active, and some missions deliberately ended their spacecraft (for example, Cassini's planned plunge into Saturn).
